# 고양이 그림 추가 요청 (v3)

## 왜 필요한가

지금 그림(오렌지 기준 21장)은 한 장 한 장은 예쁘지만, 연속 동작으로 이어 그린 게 아니라서 끊겨 보인다.

- **걷기 6장:** 꼬리 위치가 장마다 제멋대로(위 → 아래 → 위)라 꼬리가 깜빡인다. 머리 높이와 귀 모양, 몸 길이도 장마다 달라서 머리가 떨린다. 다리도 "앞발 닿기 → 지나가기 → 뒷발 닿기" 순서로 이어지지 않는다.
- **달리기 6장:** 몸 높이가 장마다 크게 다르다(바닥에 붙은 장 ↔ 높이 뜬 장). 꼬리도 순서 없이 바뀐다.
- **자세 사이 연결 그림이 없다:** 앉기 → 서기, 서기 → 눕기, 방향 바꾸기가 한 장에서 다른 장으로 순간이동한다.
- **"서 있기" 그림이 없다:** 걷다가 잠깐 멈추면(방향 바꾸기 전 0.6초, 목적지 도착, 집 들어가기 전 대기) 걷기 그림 중간 장면이 그대로 멈춰 보인다. 사냥 자세와 공 지켜보기도 달리기 그림 한 장(10번)을 써서, 뛰다 멈춘 것처럼 보인다.

## 공통 규칙 (모든 그림)

1. 지금 오렌지 고양이와 **같은 캐릭터, 같은 크기, 같은 화풍**. 투명 배경, 오른쪽을 보는 옆모습.
2. **한 동작은 한 장의 시트에 순서대로** 그린다. 칸 크기 동일, 바닥선 동일.
3. 연속 동작 안에서는 **머리 크기, 머리 높이(±2px), 귀 모양, 몸 길이가 같아야 한다.** 움직이는 건 다리, 꼬리, 그리고 정해진 만큼의 몸 위아래뿐.
4. **꼬리는 부드럽게 이어서** 움직인다(한 사이클에 한 번 흔들림). 장마다 새 꼬리 모양을 만들지 않는다.
5. 마지막 장 다음에 첫 장이 바로 이어져야 한다(반복 동작).
6. **먼저 오렌지만** 만든다. 앱에 넣어서 확인한 다음에 나머지 7색을 같은 포즈로 만든다.

## 필요한 그림 (오렌지 1마리 기준)

### 1순위: 끊김을 제일 많이 줄이는 것 (27장)

| 동작 | 장수 | 설명 |
|---|---|---|
| 서 있기 | 1 | 네 발로 가만히 선 기본 자세. 걷기와 달리기의 시작과 끝. |
| 서서 쉬기 반복 | 3 | 서 있기에서 꼬리만 천천히 좌우로(1 → 2 → 3 → 2 반복). |
| 걷기 사이클 | 8 | 오른앞발 닿기 → 내려앉기 → 지나가기 → 올라오기 → 왼앞발 닿기 → 내려앉기 → 지나가기 → 올라오기. 머리는 거의 고정, 몸은 1~2px만 오르내림. |
| 달리기 사이클 | 8 | 뒷발 차기(코 위로) → 공중에서 길게 펴짐(꼬리 뒤로 일자) → 앞발 착지(코 아래로) → 몸 웅크림(꼬리 위로 말림) → … 다시 차기. 몸 높이 변화는 작게. |
| 방향 바꾸기 | 4 | 오른쪽 보기 → 3/4 정면 → 정면 → 3/4 왼쪽. 반대 방향은 좌우 반전으로 해결. |
| 서기 ↔ 앉기 | 3 | 서 있기와 지금 앉기 그림 사이의 중간 3장. 거꾸로 재생하면 앉았다 일어나기. |

### 2순위: 쉬는 동작을 자연스럽게 (19장)

| 동작 | 장수 | 설명 |
|---|---|---|
| 앉기 ↔ 식빵 | 3 | 앉은 자세에서 몸을 낮춰 식빵 자세가 되는 중간 장면. |
| 식빵 → 웅크려 자기 | 3 | 식빵에서 몸을 말아 지금 자는 그림이 되는 중간 장면. |
| 자는 숨쉬기 | 2 | 자는 자세에서 배만 아주 살짝 커졌다 작아짐. |
| 그루밍 반복 | 4 | 앞발 들기 → 핥기 → 얼굴 닦기 → 앞발 내리기. |
| 기지개 | 5 | 서 있기 → 앞으로 엎드려 늘이기(엉덩이 위로) 2장 → 뒷다리 뒤로 늘이기 2장. 끝나면 서 있기로 돌아옴. |
| 하품 | 2 | 앉은 자세에서 입 벌리기 2장. |

### 3순위: 사냥과 놀기 (14장)

| 동작 | 장수 | 설명 |
|---|---|---|
| 몸 낮추기 | 2 | 서 있기 → 배를 바닥에 붙인 사냥 자세. |
| 살금살금 걷기 | 4 | 낮은 자세로 천천히 기어가는 반복 동작. |
| 엉덩이 씰룩 | 2 | 낮은 자세에서 엉덩이만 좌우로(반복). |
| 덮치기 | 4 | 박차기 → 공중 → 앞발 착지 → 정리. |
| 공 치기 | 2 | 앉거나 낮은 자세에서 앞발로 툭 치기. |

### 4순위: 들어 올렸을 때 (2장)

| 동작 | 장수 | 설명 |
|---|---|---|
| 매달려 버둥 | 2 | 지금 매달린 그림(3장)에서 뒷다리만 살짝 움직이는 2장. |

## 개수 정리

- 1순위만 해도 체감이 크게 좋아진다: **27장**
- 전부: **62장** (오렌지 1마리 기준)
- 8색 모두 하면 62 × 8 = 496장이라, 오렌지로 확인한 다음 색을 늘리는 순서를 추천.

## 코드 쪽에서 같이 할 것 (그림과 별개)

- 걷기/달리기 중 멈췄을 때는 "서 있기"를 쓰게 한다. 지금은 걷던 중간 장면이 멈춰 보인다.
- 사냥 자세와 공 지켜보기에 달리기 장면 대신 전용 그림을 쓴다.
- 동작이 바뀔 때 중간 그림(서기 ↔ 앉기, 방향 바꾸기 등)을 먼저 재생하고 넘어가게 한다.
- 다리 움직임은 지금처럼 걸은 거리에 맞춰 넘기되, 8장 기준으로 바꾼다.
